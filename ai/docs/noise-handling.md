그림: [figures/noise_pipeline_B1.png](figures/noise_pipeline_B1.png) — `demo_normal_B1` 의 0.6초 구간.
다시 그리기: `..\..\.venv\Scripts\python.exe scripts\figure_noise_pipeline.py --session <세션 폴더> --out docs\figures\<이름>.png`

> 현재 수치는 **모크 데이터**(샘플 클릭 16개 + 합성 소음) 기준이다. 실측 성능이 아니다.

## 1. 운영 소음 조건(B)에 들어 있는 소리

| 소리 | 특징 | 클릭과 헷갈리는 정도 |
|---|---|---|
| 펌프 웅웅거림 | 60 Hz 와 배음(~500 Hz), 계속 남 | 낮음 — 주파수가 전혀 다름 |
| 수류 | 400 Hz 이하 저주파 | 낮음 |
| 에어레이션 쉿 소리 | 2–15 kHz 넓은 잡음, 계속 남 | 중간 — 클릭 대역과 겹쳐 약한 클릭을 묻음 |
| 기포 터짐 | 1–6 kHz 짧은 울림(2–6 ms), 초당 약 3회 | **높음** — 짧고 뾰족해서 크기만 보면 클릭처럼 보임 |
| 장비 충격 | 0.1–16 kHz 넓은 대역, 0.25초 | 중간 |
| 사료 입수·알갱이 충돌 (두 조건 공통) | 급이 순간, 2–5 kHz 짧은 울림 | 높음 |

## 2. 처리 단계

녹음을 깨끗하게 "지우는" 방식이 아니라, **원신호는 그대로 두고 클릭만 골라내는** 방식이다.
모든 단계가 과거 데이터만 쓰므로 실시간 입력에서도 똑같이 동작한다.

1. **대역통과 필터 (2–20 kHz, 4차 Butterworth)**
   펌프 웅웅거림과 수류 저주파를 통째로 제거한다. 클릭 에너지(9–13 kHz)는 그대로 남는다.
   → 그림 ③: 저주파 출렁임이 사라짐.
2. **에너지 포락선**
   신호를 제곱하고 1.5 kHz 저역통과로 매끄럽게 만든다. 3 ms 짜리 클릭이 뾰족한 봉우리 하나로 바뀐다.
3. **적응 임계값 (최근 5초 잡음 수준 × 8)**
   50 ms 마다 잡음 수준(중앙값)을 재고, 최근 5초 값들의 중앙값을 기준으로 삼는다.
   에어레이션 세기가 바뀌어도 기준이 따라 움직인다. 일부러 낮게 잡아 클릭을 놓치지 않는다(후보 재현율 100%).
   → 그림 ④: 클릭 2개와 함께 기포 1개도 후보로 잡힘.
4. **최고점 찾기 + 10 ms 병합**
   10 ms 안의 봉우리는 하나로 합쳐 한 클릭이 두 번 세어지지 않게 한다.
5. **CNN 판정**
   후보 주변 32 ms 를 스펙트로그램(1–20 kHz)으로 바꿔 작은 CNN 이 클릭인지 판정한다.
   클릭은 "9–13 kHz 에 짧고 넓게 퍼진 세로줄", 기포는 "1–6 kHz 에 좁게 울리는 소리"라는 모양 차이로 구분한다.
   패치마다 배경 수준을 빼서(중앙값 정규화) 쉿 소리 세기와 무관하게 모양만 본다.
   → 그림 ⑤: 클릭 2개는 인정(0.69, 0.58), 기포는 버림(0.03).

**핵심: CNN 은 B 조건 소리를 한 번도 학습하지 않았다.** 조용한 A 수조로만 학습하고 일반 백색 잡음만 섞었다.

## 3. 결과 (B 수조 2–4일차, 모크)

| 방식 | Precision | Recall | F1 | 분당 클릭 수 오차 |
|---|---|---|---|---|
| 신호처리만 (설계서 Day 1 게이트로 임계값 결정) | 0.912 | 0.905 | 0.909 | 2.91 |
| 신호처리 후보 + CNN (A 로만 학습) | 0.9995 | 0.933 | **0.965** | **2.20 (−24%)** |

- 신호처리만 쓰면: 임계값을 낮추면 기포를 클릭으로 세고(오검출 2.9회/분), 높이면 약한 클릭을 놓친다.
- CNN 을 더하면: 오검출 0.02회/분. 다만 쉿 소리에 묻힌 약한 클릭을 약 7% 놓쳐 AUC 가 실제보다 약 7% 낮게 잡힌다.
  정상 기준도 같은 검출기로 만들기 때문에 이상 판정에는 영향이 작다.

## 4. 하지 않은 것 · 한계

- 계획안에 적었던 **스펙트럼 차감(spectral subtraction) 같은 잡음 제거는 아직 비교하지 않았다.**
  지금은 "잡음을 지우지 않고 검출을 강하게" 하는 방식만 있다. 실측 데이터에서 약한 클릭 누락이 크면 비교할 후보.
- 합성 소음은 실제 양식장 소리를 녹음한 것이 아니다. 실측 데이터로 대역(2–20 kHz)·임계값(×8)을 Day 1 게이트로 다시 정한다.
